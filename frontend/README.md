# Interior Design Matching Platform - Frontend

React + Vite frontend for the CSIT314 group project.

## Setup

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Backend

The frontend connects to the Django backend at `http://127.0.0.1:8000`.
Make sure the backend is running first:

```bash
cd ../backend
python manage.py runserver
```

## Tech Stack

- React 18
- Vite
- Material UI (MUI)
- Chart.js + react-chartjs-2
- Axios
